# Aidan's personal website

A minimal landing page for GitHub Pages, with a charcoal background and a typed greeting. Plain HTML and CSS; no installation or build step required.

## Edit and preview

1. Open this folder in VS Code.
2. Install Microsoft's **Live Preview** extension (`ms-vscode.live-server`), included in this workspace's extension recommendations.
3. Open `index.html` and click the preview button at the top right of the editor.
4. Drag the preview tab into the right editor group to keep code and the live website side by side. The preview updates as you edit.

You can also open `index.html` directly in a browser; refresh it after saving changes.

## Files

- `index.html`: page content and metadata.
- `styles.css`: colors, layout, and typing animation. The animation runs once on each page load and is disabled for visitors who prefer reduced motion.
- `CNAME`: the existing custom domain for GitHub Pages.

## Publish

Commit and push these files to the branch configured for GitHub Pages. For branch-based publishing, select the repository root (`/`) in **Settings → Pages**. No build tooling is needed.
